Il y a 5 branches : 
- La branche "Main" présente le code utilisé pour extraire les données ATL08 d'ICESat-2
- La branche "Comparaison_Point_Par_Point_Bassin_Complet
- La branche "Comparaison_Grille_Bassin_Complet"
- La branche "Comparaison_PP_Floodpath" présente les codes pour la comparaison point par point sur le chemin d'inondation
