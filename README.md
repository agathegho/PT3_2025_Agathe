Codes créés pour répondre à la problématique suivante : Quel MNT est le plus précis, comparé aux données ATL08 d'ICESat-2. 
Les codes avec FP dans le titre sont les codes associés au chemin d'inondation (FloodPath). 
Les codes avec PP dans le titre sont les codes associés à la comparaison point par point
Les codes avec BC dans le titre sont les codes associés au Bassin Complet
